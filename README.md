## About me

- 🔬 Applied research in **computer vision**: deep-learning individual tree detection in airborne LiDAR ([TreeSeg-ALS](https://github.com/jossuema/treeseg-als)), reproducibility code for a manuscript submitted to *Forests* (MDPI).
- 🎤 Speaker at **FLISOL 2026** — improving small-object detection in aerial imagery with [YOLO + SAHI](https://github.com/jossuema/yolo-sahi-flisol2026), evaluated on VisDrone.
- 📡 I like building **end to end**: SISCA, a BLE access-control system with on-device face recognition, spans ESP32 firmware, native Android & iOS apps, and a FastAPI backend.
- 🌐 More about me at [jossuema.tech](https://jossuema.tech).

## Featured projects

| Project | What it is | Stack |
|---|---|---|
| [TreeSeg-ALS](https://github.com/jossuema/treeseg-als) | Inventory-anchored evaluation of deep-learning tree detection in airborne LiDAR (ALS), with label-efficient cross-domain transfer in alpine forests | Python · PyTorch · PointNet++ |
| SISCA — [Android](https://github.com/jossuema/sisca-mobile) · [iOS](https://github.com/jossuema/sisca-mobile-ios) · [Firmware](https://github.com/jossuema/sisca-esp-platformIO) · [API](https://github.com/jossuema/API-SISCA) | BLE access control for UTMACH: ESP32 (NimBLE) firmware, native apps with on-device face recognition (ML Kit + TFLite) and biometric auth, REST backend | Kotlin · SwiftUI · C++ · FastAPI |
| [AquaLens AI](https://github.com/jossuema/aqualens) | Desktop app that detects and counts fish in underwater video with a two-phase OpenCV + YOLO pipeline | Python · OpenCV · YOLO |
| [YOLO + SAHI](https://github.com/jossuema/yolo-sahi-flisol2026) | FLISOL 2026 talk & demo: small-object detection for urban aerial imagery with real mAP metrics | Python · YOLO · SAHI |
| [Buzón Inteligente UTMACH](https://github.com/jossuema/buzon-electronico-utmach) | University participation platform (complaints, suggestions, proposals) with an admin analytics dashboard | Next.js · Prisma · PostgreSQL |
