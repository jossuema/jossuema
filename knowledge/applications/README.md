# Applications tracker

Every scholarship, program, conference, or job application: target,
deadline, status, outcome. One file per active application
(`YYYY-MM-name.md`) capturing requirements, essay prompts, and exactly
what was submitted — accepted materials become reusable templates.

## Per-application file template

```markdown
# <Opportunity> — <deadline>
- Link, type, funding amount
- Requirements checklist (letters: who? see ../references.md; docs: see ../credentials.md)
- Essay prompts + word limits
- Drafts (link to ../statements/)
- Submitted on <date>: exact files
- Result + feedback
```
