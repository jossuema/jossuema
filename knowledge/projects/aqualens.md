# AquaLens AI

Desktop app that detects and counts fish in underwater video.

- **Sources:** GitHub profile README,
  [repo](https://github.com/jossuema/aqualens)
- **Area:** computer vision, aquaculture

## What it is

A desktop application that detects and counts fish in underwater video with
a **two-phase OpenCV + YOLO pipeline**.

- **Stack:** Python, OpenCV, YOLO
