# TreeSeg-ALS

Deep-learning individual tree detection in airborne LiDAR (ALS).

- **Sources:** GitHub profile README,
  [repo](https://github.com/jossuema/treeseg-als)
- **Area:** 3D deep learning, LiDAR, forestry
- **Status:** reproducibility code for a manuscript submitted to *Forests*
  (MDPI) — see
  [`../research/treeseg-als-forests.md`](../research/treeseg-als-forests.md)

## What it is

Inventory-anchored evaluation of deep-learning tree detection in airborne
laser scanning (ALS) data, with label-efficient cross-domain transfer in
alpine forests.

- **Stack:** Python, PyTorch, PointNet++

## Reuse notes

- This is the flagship *research* project: manuscript + open
  reproducibility code.
- "Label-efficient cross-domain transfer" is the phrase to reuse in research
  statements.
