# Sources

Canonical source documents for the knowledge base. Everything in `knowledge/`
should be traceable to a file here or to a public artifact.

- [`cv-2026-08.md`](cv-2026-08.md) — full transcription of `cv/cv.pdf`
  (CV as of August 2026).

## Adding new material

When new information arrives (an acceptance letter, a program description,
notes about a talk), save it here first as a dated file
(`YYYY-MM-topic.md`), then distill it into the appropriate `knowledge/` file.
Keep the raw material — it is what you will quote in applications.
